Disasters, outbreaks and Red Cross appeals, listed as ReliefWeb, GDACS, USGS, WHO, IFRC and NASA publish them. Nothing here is scored or ranked; the Neglect Score on the funding page is a separate analysis.

Sources. ReliefWeb (UN OCHA) disasters marked ongoing or alert; GDACS (EU and UN) Orange and Red alerts from the last 30 days; USGS significant earthquakes of the past week; WHO Disease Outbreak News (latest 15); IFRC GO active Red Cross and Red Crescent appeals; NASA EONET open storms, volcanoes and wildfires over 10,000 acres. Each event links to the original. Dates and severity words are each source's own, and a start date is when the source says it began, not when it was listed. A missing event means the source did not list it, not that nothing happened. Merging. Listings from different sources are merged when they name the same first country and the same type of event within 30 days of each other. That can join two separate floods in one country, so you can switch it off above the list. The data file is rebuilt about every 30 minutes by a GitHub Action, and this page re-reads it and checks USGS directly every 5 minutes while it is open. Conflict events and hunger (ACLED, IPC) are not included yet. The blue dot marks events that appeared since this browser last visited.
